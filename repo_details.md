```bash

git clone https://github.com/PrincePanara/cerateprojectdoc.git

# SSH
git clone git@github.com:PrincePanara/cerateprojectdoc.git
```

### 🔄 Sync with Remote
```bash
# Fetch latest changes
git fetch origin

# Pull latest updates
git pull origin main

# Push changes
git push origin main
```

- **Frontend:** React 18, TypeScript, Vite
- **Styling:** Tailwind CSS 3, Lucide React
- **Document Generation:** `docx` (OpenXML document generation)
- **Animation & UI:** Framer Motion, `@emotion/react`
